# Release notes

## 0.4.0 – NEXUS ONE (2026-11-21)
* **Renamed to NEXUS ONE.** Same install location and settings, so an update keeps your data.
* **Bulk Rename rebuilt.** Ordered rules you can reorder and untick; CSV/Excel rename lists; tokens for parent folder, dates, size and file content; folders together with their contents; complete before/after list before confirming; automatic rollback if a file is locked; undo from the history; profiles.
* **Directory Listing & Reports.** Filters by name, regex, size and dates; 16 columns incl. SHA-256 and folder totals; grouping; statistics; empty folders; tree diagram; export to Excel, CSV, TXT, HTML, PDF, Markdown, XML and JSON; print preview; templates.
* **Duplicate Finder (new module).** Identical files, same names, renamed copies, near-duplicate text, version series and grouping. It never deletes anything.
* **Automation.** New job types `dir_report`, `duplicates` and `rename_preview`, plus a "Delivery workflow" template.
* Conflicts are shown in orange.
